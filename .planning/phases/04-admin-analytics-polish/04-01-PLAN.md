# Plan 04-01: Admin Analytics & Polish

We will implement custom-crafted HSL SVG area trend graphs and responsive CSS flex classroom breakdown bar charts inside the Overview hub dashboard, fully integrated with real-time class data and simulated logs fallback.

---

## Proposed Changes

### Component: Dynamic Dashboard Analytics

#### [MODIFY] [page.tsx](file:///d:/New%20folder%20%283%29/src/app/dashboard/page.tsx)
* **Statistics & Math Sync**:
  * Extract live counts of registered students and total classroom sections dynamically from local database routes.
  * Fetch aggregate parent notifications sent from the logs API.
* **Visual SVG Area Trend Graph**:
  * Renders a gorgeous modern SVG area chart plotting weekly school attendance levels (Monday to Friday).
  * Styled with a linear color gradient fill (`#4f46e5` to transparent), glowing vector lines, circular data dots, and grid guide lines.
  * Integrates dynamic cursor hovers and labels.
* **Classroom Attendance Breakdown Bar Graph**:
  * Program a horizontal/vertical hybrid visual bar widget displaying active sections side-by-side.
  * Formulate dynamic bar heights reflecting actual daily attendance averages (e.g. 100% for Grade 10 - Section A, 90% for Grade 9 - Section A).
  * Design curated HSL bar color indicators (success emerald for rates >95%, warning orange for rates <95%, error danger for rates <90%).
  * Include interactive card panels with hover glow outlines and dynamic indicators.
