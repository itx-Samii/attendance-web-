# Phase 5 Plan 05-01 — Roster Directory & Attendance Ledger

We will build the premium Roster Directory (with full runtime edit/delete capabilities) and monthly Attendance Ledger calendars.

---

## Proposed Changes

### Backend API Layers

#### [NEW] [route.ts](file:///d:/New%20folder%20%283%29/src/app/api/classes/route.ts)
* Add `PUT` and `DELETE` handlers to `/api/classes` route:
  * `PUT`: Receive `{ classId, name }`, edit classroom in `classes.json`, and return success.
  * `DELETE`: Receive `classId`, remove class from `classes.json`, and cascade-delete or unassign students in `students.json`.

#### [NEW] [route.ts](file:///d:/New%20folder%20%283%29/src/app/api/students/route.ts)
* Add `PUT` and `DELETE` handlers to `/api/students` route:
  * `PUT`: Receive `{ rollNumber, name, parentPhone, classId }`, edit student details in `students.json`, and return success.
  * `DELETE`: Receive `rollNumber`, remove student from `students.json` atomically.

### Frontend UI Components

#### [MODIFY] [DashboardLayout.tsx](file:///d:/New%20folder%20%283%29/src/components/DashboardLayout.tsx)

#### [NEW] [page.tsx](file:///d:/New%20folder%20%283%29/src/app/dashboard/directory/page.tsx)
* Build a premium **Roster & Ledger** dashboard view:
  * **Top Panel Tab Selector**: Switch seamlessly between **"Roster Directory"** (Tab 1) and **"Attendance Ledger"** (Tab 2).
  * **Tab 1: Roster Directory**:
    * Sidebar classroom list with "Edit Name" and "Delete Class" buttons.
    * Main table displaying students registered in the selected class (Roll, Name, Parent Contact, Actions: Edit Details / Delete Student).
    * Dynamic inline edit modals with curated backdrop-blur visual designs.
  * **Tab 2: Attendance Ledger**:
    * Select Classroom and Month/Year dropdown options.
    * Dynamic Grid Calendar displaying a beautiful data matrix: Students as rows, and calendar days of the month (e.g. 1st to 31st) as columns.
    * Color-coded attendance status circles inside the ledger cells (emerald P, crimson A, orange L, purple Leave) loaded in real-time from `attendance.json`.
